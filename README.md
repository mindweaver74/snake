# 🐍 뱀 키우기

> 먹이를 먹을수록 뱀이 길어진다! 벽과 자신의 몸을 피하며 최고 점수에 도전하는 클래식 스네이크 게임.

**▶ 지금 바로 플레이** → [https://mindweaver74.github.io/snake/](https://mindweaver74.github.io/snake/)

---

## 🎮 게임 방법

1. 방향 버튼 또는 방향키로 뱀을 조종합니다
2. 화면에 나타나는 과일을 먹으면 점수 획득 + 뱀이 길어집니다
3. 과일은 항상 2개가 화면에 표시됩니다
4. 벽이나 자신의 몸에 닿으면 게임 오버!
5. ⭐ 보너스 먹이 — 5개마다 등장, 타이머 안에 먹으면 +50점

---

## 🕹️ 조작법

| 환경 | 조작 |
|------|------|
| PC | 방향키 `↑↓←→` 또는 `W A S D` |
| PC 일시정지 | `Space` / `P` / `ESC` |
| 모바일 | 화면 하단 방향 버튼 |
| 모바일 (보조) | 게임판 스와이프 |
| 게임 시작/재시작 | 방향키 / `Enter` / `Space` / 시작 버튼 |

---

## ✨ 주요 특징

- 🍎 **과일 9종** — 사과·오렌지·레몬·포도·딸기·체리·키위·바나나·블루베리 랜덤 등장
- 🟢 **항상 2개 먹이** — 먹자마자 즉시 다음 먹이 등장, 대기 시간 없음
- ⭐ **보너스 먹이** — 5개마다 별이 등장! 타이머 바 표시, 50점 보너스
- ⚡ **자동 속도 증가** — 10개마다 빨라짐 (보통→빠름→매우빠름→초고속)
- ⏸ **일시정지** — 중앙 버튼 또는 스페이스바
- 💾 **최고 점수** — 로컬 저장
